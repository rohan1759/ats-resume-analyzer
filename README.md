# 🚀 ATS Resume Analyzer

An AI-powered web application that analyzes resumes against job descriptions and provides ATS-based scoring, keyword matching, and improvement suggestions.

---

## 📌 Features

* 📄 Upload Resume (PDF/DOCX)
* 📝 Paste Job Description
* 🤖 AI-based Resume Analysis
* 📊 ATS Compatibility Score
* 🔑 Keyword Matching
* 💡 Actionable Suggestions for Improvement
* ⚡ Fast & Clean UI (React + Tailwind)

---

## 🧠 How It Works

1. Upload your resume
2. Paste the job description
3. The system extracts and analyzes text
4. Calculates ATS score based on keyword match
5. Displays:

   * Match Score
   * Missing Keywords
   * Improvement Suggestions
